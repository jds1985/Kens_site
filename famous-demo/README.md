# Famous reference restoration

This folder is a static copy of the October 28, 2026 Famous page for the Invisible Society, rebuilt from the preserved rendered markup and stylesheet. It is not the live site and it does not sign anyone in.

The type, star field, gold heading, navigation, tree diagram, and section images come from that reference. The fourteen photographs are the public CloudFront files the reference page displays. Rights were not verified here; they are included because Jim asked for this design to be restored. The original compiled application script is not included. There is no Supabase, CRM, payment, or mail connection.

`demo.js` only scrolls to the sections already in the page, opens the phone menu, and stops forms and Sign In. Those actions show a local note instead of contacting a server.

Images and `assets/reference.css` are part of the public Famous package. `README.md` and `test_demo.mjs` stay out of the Vercel upload.
