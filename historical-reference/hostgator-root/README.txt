HISTORICAL SOURCE ONLY. These files are not routes and must not be copied into preview/ or any public web root.

25 HostGator Website Builder viewer wrappers are kept here with a .source.txt suffix. banner.html and banner.css are the same kind of reference. banner.png is the HostGator promotional banner image. None of these are standalone pages, and none replace the current homepage.

Independent review of this public import found generated storage URLs that embed one numeric builder account id and site id. Every occurrence of that path was replaced with wzukusers/user-REDACTED/sites/REDACTED (297 replacements across the 25 wrappers). Because of that redaction, these .source.txt files are not byte-identical to the private originals. The original URL list was not committed.

No payment-contact values, credentials, password hashes, member records, or private lesson bodies were found in these 25 wrappers. EMAIL, PHONE, and Telephone labels in the contact shell are empty builder labels. "payment processors" appears only inside HostGator product-feature boilerplate.

81 other viewer shells were withheld before this handoff and are not in this repository. Do not fetch viewer.js, viewer.css, or the generated storage scripts these wrappers name. Do not publish any of these files as HTML.
